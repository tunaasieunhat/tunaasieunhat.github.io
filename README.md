# tunaasieunhat.github.io

Trang gốc cho các ứng dụng của tunaasieunhat trên GitHub Pages.

- `index.html`: trang giới thiệu, dẫn tới [Ôn Luyện Nha Khoa](https://github.com/tunaasieunhat/on-luyen-nha-khoa) bản Offline và Online.
- `.well-known/assetlinks.json`: xác nhận app Android "Ôn Luyện Nha Khoa" (gói `io.github.tunaasieunhat.onluyennhakhoa`) thuộc về trang này, để app mở toàn màn hình, không hiện thanh địa chỉ.
- `.nojekyll`: để GitHub Pages phục vụ thư mục `.well-known`.
