# tunaasieunhat.github.io

Trang giới thiệu app **Ôn Luyện Nha Khoa**: https://tunaasieunhat.github.io/

- `index.html`: trang quảng bá (tính năng, môn học, các bản cập nhật, link tải app Android và bản web). Chỉ một file HTML, không cần build.
- `img/`: ảnh chụp màn hình app (WebP) và mã QR tải app / mở bản web.
- `fonts/`: phông Baloo 2 và Be Vietnam Pro (giấy phép SIL Open Font License) lưu sẵn để trang không phụ thuộc Google Fonts.
- `.well-known/assetlinks.json`: xác nhận app Android "Ôn Luyện Nha Khoa" (gói `io.github.tunaasieunhat.onluyennhakhoa`) thuộc về trang này.
- `.nojekyll`: để GitHub Pages phục vụ thư mục `.well-known`.

Bản web của app nằm ở repo [on-luyen-nha-khoa](https://github.com/tunaasieunhat/on-luyen-nha-khoa): https://tunaasieunhat.github.io/on-luyen-nha-khoa/

Sửa nội dung: mở `index.html` trên GitHub, bấm biểu tượng bút chì, sửa chữ rồi **Commit changes**; khoảng 1 phút sau trang tự cập nhật.
